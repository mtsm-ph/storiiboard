# Brief 6.14, review fixes

Read docs/briefs/6.14-contract-test.md first: this continues it, same rules. Nothing high; fix these.

1. **(Medium) Ways of reaching `invoke` the contract test doesn't see** (src/app/tauriContract.test.ts): a re-export
   of `invoke` (`export { invoke } from '@tauri-apps/api/core'`, `export *`), an import from the root package
   (`import { core } from '@tauri-apps/api'`), and a wrapper imported through a barrel, a non-relative path or
   double quotes. Example that passes today: a file re-exports `invoke`, another imports it from there and calls
   `invoke('sbd_close', { handel })`. Make the test fail on: any import from `@tauri-apps/api` or its submodules
   other than the ones it understands (list them in the test), any export of anything from `@tauri-apps/api/core`,
   and any import of a WRAPPERS name it can't resolve to the listed wrapper. Add parser unit cases for each.
2. **(Low) nodeDriver stricter than Rust:** a blob read takes `Object.values(row)[0]`, which isn't always the first
   column (`SELECT bytes, 1 …` puts the column named "1" first; `SELECT bytes AS b, mime AS b` keeps the later
   value). Read the first column by position, as the memory driver now does. Test both statements over both
   drivers.
3. **(Low) Both drivers looser than Rust:** `query('SELECT bytes AS v, sha256 AS v …')` builds rows by name, so the
   blob is hidden behind the later column and gets through; Rust refuses it. Refuse by position (every value of
   every row as the statement returns it, before rows become objects). Test over both drivers; pin it in sbd.rs's
   test too if it isn't already.
4. **(Low)** An unused `BUILT_IN_EVENTS` entry should fail like the other allowlists, or the list should hold only
   what the page uses today (it uses none: then it is empty and a first use adds its entry). The Rust-emits scan
   drops everything after the first `#[cfg(test)] mod tests` in a file and misses `Emitter::emit(&app, …)` written
   as a function call: handle both, or fail loudly when a file has code after its test module.
5. **(Low)** `everything()` in projectJson.test.ts lists columns through `pragma_table_info`, which leaves out
   generated and hidden columns that `SELECT *` included: use `pragma_table_xinfo` or assert the table has none.
