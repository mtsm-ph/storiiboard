# Brief 6.19b, review fixes

Read docs/briefs/6.19b-mac-webkit-second-run.md and 6.15-review-fixes.md first: this continues them, same rules.
All low; fix 1 to 4. (The reviewer's one medium, plan.spec.ts lacking the whole-pixel helper, is brief 6.19c's.)

1. **A colour panel or a frame's menu can stay open with focus outside it, in every engine**
   (ColourControl.tsx near 106, AddToBoardMenu.tsx near 114): 6.19b lets focus go to any ancestor without
   closing. Click the gap between two swatches: focus goes to `#workspace-panel`, the panel stays open, and then
   Escape and Tab do nothing for the colour panel (its key handler is on its own root). Allow the ancestor only
   during a press that began inside the panel (set on pointerdown inside, cleared at that press's click or
   pointerup/cancel); any other focus move to an ancestor closes it as before 6.19b. After such a press, if focus
   is left on an ancestor, put it back on the control that had it (so Escape and Tab still work). Tests in
   e2e/macWebKit.spec.ts: a press in the panel's padding leaves it open and Escape then closes it; Tab from the
   panel to outside closes it; 6.19b's two tests stay green.
2. **The Setups tile's drop bar moved 0.75 px** (src/ui/useRowDrag.ts near 72: the new clamp applies with no
   scroller too): with no `scroller`, place the bar exactly as before 6.15's review fixes.
3. **The export's `"end"` action is never tested through `export_write`**: add a mock-runtime test
   (src-tauri/src/export/ipc_tests.rs) that sends the header the page sends (copy it from
   src/core/storage/exportFiles.ts) through the registered command and then shows the file can't be written; and
   a Vitest test that the page's header for `end` is exactly `{ action: 'end', … }` as Rust's dispatch reads it
   (read export.rs as text for the action names, as exportExtensions.test.ts does for extensions).
4. **`dragSofaTo` in e2e/planUnderlay.spec.ts** computes its start point, then a second `screen()` call may resize
   the viewport and leave the start stale: compute both points after one whole-pixel check (arrangement only).
5. Notes, no change: noHtmlDrag.test.ts and the contract test can be dodged by building the words from pieces;
   there is no junction test for Show backups on Windows.
