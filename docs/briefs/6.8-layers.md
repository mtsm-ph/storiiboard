# Brief 6.8: layers

Phase 6, milestone 6.8 (docs/PLAN.md; docs/PHASE6_DECISIONS.md decision 10). Read CLAUDE.md first (its
"Bird's-eye view" rules and "Department status … Perspective views (3.6c)": a focus view, not access control),
then decision 10, then the briefs of what is built (6.2a to 6.7 in docs/briefs). Stay on the branch checked out.

## Goal

The Layers tile goes live: each department's layer of the plan can be shown, dimmed, hidden and locked, and a
person starts on their own department's layer with the others dimmed.

## Decisions that apply

- **A focus view, never access control** (decision 10, as 3.6c): layers change only what this person sees and can
  pick on this computer. Nothing about layers is written to the project file, no op, nothing in History.
- **An item's layer comes from what it is, worked out, never stored** (`planItemLayer` in src/core/model/plan.ts
  already does this for icons, cameras and lights; complete it): camera (cameras, their marks and paths),
  lighting (lights, the sun path), grip (flags, diffusion, grip hardware), art (walls, doors, windows, set
  pieces, the room's north), cast (marks of characters, plain marks, eyelines, background), sound, production
  (production items, measures when 6.9 adds them). The underlay (6.9) is its own row, "Underlay", not a
  department. Layer names through `t()` using the department names the app already has.
- **Per layer**: Shown, Dimmed or Hidden (one choice of three) and Locked (a switch). Dimmed draws at reduced
  opacity (the canvas core's `dim`); Hidden is not drawn and not picked; Locked is drawn but not picked by click,
  marquee, Tab, select-all, the context menu or double-click (the core's `locked`), and tools don't snap-select
  it, though snapping to its points still works. A hidden or locked layer's items are never changed by a marquee
  or select-all followed by Delete. Whatever is currently selected stays selected only if still pickable.
  - A door or window follows its wall's layer (art). A wall hidden with openings: both hidden.
  - Placing an item whose layer is hidden or locked: the layer is switched to Shown and unlocked, with the
    app's usual notice saying so (never place something the person can't then see).
- **Where the state lives**: this computer's settings (src/core/storage/settings.ts), one state for all plans:
  `planLayers: { [layer]: { show: 'shown' | 'dimmed' | 'hidden', locked: boolean } }`, with a migration default.
- **The starting state** (when the setting has never been set): from "This is me" (the reader 3.10 and 3.6c
  use: find it) and that person's department: camera → the camera layer shown, the rest dimmed; grip and
  electric → lighting and grip shown, the rest dimmed; art → art shown; cast → cast shown; sound → sound;
  production → production; everyone else, the director, the DP and anyone with Full view (3.6c's switch): all
  shown. Nothing locked. A "Show all" button and a "My department" button in the tile set these two states at
  any time.
- Export (6.10) will print every layer unless told otherwise; nothing to do here except keep the layer function
  in the model.

## What to build

1. The layer function completed for every kind (model, with a test that every kind and every icon group maps to
   exactly one layer).
2. The settings field with its default and migration; a small store both the Plan and Layers tiles read.
3. The plan host applies the state when building canvas items (`dim`, `locked`, or left out), memoised with the
   state in the key; picking, marquee, Tab order, select-all, snapping and the spoken count respect it.
4. **The Layers tile** (workspace tile id `layers`; map it in src/app/shell/tileContent.tsx): one row per layer
   in call-sheet order with its department colour as a small tag (department colours are tags, never state),
   how many items the shown plan has on it (mono), the Shown / Dimmed / Hidden choice (a three-way control from
   src/ui), the Lock switch, and "Solo" (this layer shown, the others dimmed; pressing again restores what was
   before). Rows for layers with no items are muted. Every control keyboard reachable with a spoken name that
   says the layer and the state. Keys on the plan, if free: 1 to 7 solo a layer, 0 shows all (say what you chose).
5. The Plan tile's header shows a small note when anything is hidden or locked ("2 layers hidden"), so a person
   isn't confused by a missing item, with a button to show all.
