# Brief 4.11: only frames still to shoot on the call sheet

For the builder (.claude/agents/builder.md). Written by the main session, Nov 10, 2026. Read CLAUDE.md first; its
Safety section comes before this brief.

## Goal (Kevin, Nov 10, answering #121)

The call sheet lists only frames still to shoot ("Need to shoot"). Frames marked Have or Source after they were put in
a day drop off the sheet; the Calendar can keep showing them as it does.

## Decisions that apply

- In src/core/model/callsheet.ts, the sheet's frames are the day's frames whose status is `need` (`shotFields(...)
  .status`, as `dayTotals` counts in src/core/model/shootDay.ts). Everything built from them follows: the scenes (a
  scene with no Need-to-shoot frames on the day leaves the sheet), each scene's frame count and locations, the day's
  locations (a location only Have/Source frames used leaves), the cast (characters of scenes that left), the checks
  (src/core/checks: they read the sheet and its CheckContext; make sure the context's frames are the same set), the
  PDF and issuing.
- `dayScenes`/`dayLocations` in src/core/model/schedule.ts stay as they are (the Calendar uses them); the call sheet
  uses its own filtered frames.
- The fingerprint (src/features/callsheets/fingerprint.ts, recipe 1, frozen): don't touch the recipe. The sheet it
  reads changes, which is right: a frame marked Have changes what prints. Issued sheets made before this change will
  read "Changed since issued" for days whose sheet loses frames; that's a real change on paper, not a format change,
  so it's allowed — say so in the PR words for Kevin.
- A day whose frames are all Have/Source shows its header, people and notes, with "Nothing left to shoot on this
  day" in the Scenes section (en and es), on screen and in the PDF.

## Tests

- Vitest: a day with Need, Have and Source frames lists only the Need ones; a scene and a location that only Have
  frames used leave; the cast follows; the checks follow (e.g. a dialogue scene whose frames are all Have no longer
  asks for Sound); the PDF text; "Nothing left to shoot".
- Playwright: mark a frame Have, see it leave the call sheet while the Calendar still shows the day's count as before.
