## The tags (the main session's proposal, shown to Kevin; one table in the code so he can change it in one place)

The kit has nine set pieces. Each can be in several rooms.

| Room | Set pieces |
|---|---|
| Living room | sofa, table, chair, plant-tree |
| Kitchen | counter-bar, table, chair |
| Bedroom | bed, chair, table, plant-tree |
| Office | table, chair, sofa, plant-tree |
| Bar | counter-bar, chair, table, column |
| Anywhere (no room of its own) | car, stairs, column, and every set piece above |

Only set pieces (the `set-art/` icons that are placed as icons: not wall, door, window, which are tools) carry
room tags. Cameras, lights, grip, sound, production and cast items are not "in a room": the By room view shows
them under their department below the rooms, unchanged.

## What to build

1. **One table** in src/features/birdseye/plan (e.g. `libraryRooms.ts`): the five rooms in Kevin's order, each
   with its name (t(), en and es: "Living room / Sala", "Kitchen / Cocina", "Bedroom / Dormitorio", "Office /
   Oficina", "Bar / Bar") and its icon ids, exactly the table above. A test asserts every id in it exists in
   iconBoxes.ts and is a placeable set piece, that every placeable set piece is in at least one room or in
   "Anywhere", and that the table equals the brief's (so a change to it is deliberate).
2. **The Library's "Sort by"**: a two-state control at the top of the Library tile: "Department" (today's
   grouping, the default) and "Room". Kept on this computer under its own storage key with a defensive reader
   (the pattern of src/app/canvasView.ts and src/core/storage/settings.ts's own-key settings; NOT a field of
   `Settings`: two tests compare that object whole; add the key to the lists in
   src/core/model/settingsPreset.ts's test: it belongs in NEVER_IN_PRESET unless a "look and layout" reading
   makes it a preset field: put it in the never list and say so). Never in the project.
   - By room: a group per room in the table's order, each listing its set pieces (an item in several rooms
     appears in each), then "Anywhere" with every set piece, then the departments' groups exactly as today for
     everything that is not a set piece. Groups fold as today's do, their folded state remembered as today's is.
   - Search, if the Library has it, works across both groupings and shows a set piece once.
   - Placing (drag, tap, keyboard) is unchanged, and an item placed from a room group is the same record as one
     placed from its department group: a room tag is never stored on a plan item.
3. Accessible: the control is a radio pair or a pressed-button pair with names; the groups are headings or
   labelled regions as today's; keyboard order unchanged within a group.
