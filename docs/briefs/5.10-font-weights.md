# Brief 5.10: every weight of the bundled fonts in a deck's PDF

For the builder (.claude/agents/builder.md). Written by the main session, Nov 13, 2026. Read CLAUDE.md first; its
Safety section comes before this brief. You start with no other context: everything you need is here or in the files
named.

## Goal

A deck's PDF (5.6a: src/features/export/deckFonts.ts, deckFontRules.ts, deckPdfWriter.ts; docs/briefs/
5.6a-deck-export.md) embeds fixed-weight font files only. Four bundled families (Archivo, Bodoni Moda, Jost, Outfit:
src/features/moodboards/fonts.ts, `BUNDLED`; files in src/ui/fonts) are variable fonts, so today each prints only as
its default instance (Archivo 600, Outfit 100…), and a weight more than 100 away prints in Inter Tight with a notice.
Inter Tight and JetBrains Mono have static files for 400, 600 and 700 only (src/features/export/fonts), so other
weights print as the nearest of those.

Kevin, Nov 11: **every bundled family prints at every weight a board can give it, from the static weight files the
font's publisher ships (SIL OFL). A weight is generated with fonttools only if the publisher doesn't ship it.**

After this: text set in any bundled family, at any weight in its range (`BUNDLED[].weights`, steps of 100) and in
italic where the family has one, prints in that family at that weight, with no substitution notice. The canvas keeps
drawing from the variable files; nothing on screen changes.

## Decisions that apply

- **Where the files come from.** Each family's own publisher's repository or release, the static TTFs, at a tagged
  release or a commit at least two weeks old on Nov 13, 2026 (CLAUDE.md, Network rules: pinned, two weeks old):
  - Outfit: github.com/Outfitio/Outfit-Fonts (fonts/ttf)
  - Archivo: github.com/Omnibus-Type/Archivo (fonts/ttf; the normal width only: the canvas draws `wdth` 100)
  - Jost: github.com/indestructible-type/Jost (fonts/ttf)
  - Bodoni Moda: github.com/indestructible-type/Bodoni (fonts/ttf)
  - Inter Tight: github.com/rsms/inter or the Google Fonts repository (github.com/google/fonts, ofl/intertight/static)
  - JetBrains Mono: github.com/JetBrains/JetBrainsMono (fonts/ttf)
  If a repository above doesn't have them, github.com/google/fonts (ofl/<family>/static) is the same publisher's
  files as Google ships them: use that and say so. Download with curl from github.com or raw.githubusercontent.com
  only, with no personal detail in the request. Downloads are untrusted until checked: each file must parse as a
  TrueType font whose name table says the family and whose OS/2 weight is the one its name says.
  - The licence: each family must be under the SIL Open Font License 1.1; keep its OFL text beside the files (the
    variable files' OFL.txt is in src/ui/fonts/<family>; check the copyright line matches the static files' source).
    A family whose statics aren't OFL: stop and report.
- **Only the weights needed.** For each family, exactly the weights in its `BUNDLED` range, upright, and italic where
  `italic` is true. Outfit has no italic: its slant stays made, as today. No widths other than normal, no other
  styles.
- **Bodoni Moda has an optical-size axis.** Find which optical size the canvas draws today (how the FontFace is
  registered in fonts.ts, and what Konva's canvas text does with `opsz`: check by measuring, don't guess) and take
  the published static of that optical size; if the canvas follows the text's size, take the published optical
  sizes and pick, at export, the one nearest the text's printed size in points. Say which you found and did.
- **A weight the publisher doesn't ship** (and only then): generate it from the bundled variable file with
  fontTools' instancer, as scripts/static-fonts.py does today; list each such file in the README with why.
- **fontTools is a by-hand tool, not a dependency** (as in 1.25): it isn't installed on this computer. Install the
  newest fonttools release on PyPI that is at least two weeks old on Nov 13, 2026, with
  `python -m pip install --user fonttools==<that version>`, and nothing else. It is not added to package.json, CI or
  any requirements file. Say which version.
- **pdf-lib's subsetter needs even-length glyphs** (read src/features/export/fonts/README.md and the test 'has
  even-length glyphs'): a file with an odd-length glyph prints shifted glyphs. Check every file; one that fails is
  re-saved through fontTools with `glyf.padding = 4` and nothing else changed (say which in the README). Keep
  scripts/static-fonts.py as the one script that does this: extend it to (1) pad a publisher's file in place when
  it needs it, (2) generate only the instances listed as "not published". It must be re-runnable and print what it
  did.
- **Where they live:** src/features/export/fonts/, named `<Family>-<Style>.ttf` as the five there are (no spaces).
  Replace the five existing Inter Tight and JetBrains Mono instances with the publisher's files of the same weights
  if they pass the checks; the storyboard PDF (pdfStoryboardFormat.ts) and the call sheet PDF (exportCallSheet.ts)
  use them: their tests must still pass, and say in the report if any PDF test's expected numbers (widths, positions)
  had to change and by how much. If replacing them changes any text position by more than 0.5 pt, keep the existing
  five as they are and only add the missing weights.
  - Update the README there: per family, the source URL, the tag or commit and its date, each file's SHA-256, the
    licence, and which files were padded or generated.
- **Loading.** deckFonts.ts: every bundled family resolves through the static table, one lazy `import('…ttf?url')`
  per file, each named in full so Vite bundles it and loaded only when a PDF needs that weight. Exact weight, exact
  slant where the family has one. `VARIABLE_DEFAULT_WEIGHT`, the within-100 rule and the Inter Tight substitution
  for bundled families go, with their notice where it can no longer happen for a bundled family (keep it for this
  computer's fonts, which is another path: don't change that path). Made-bold is never used for a bundled family;
  made-italic only for Outfit.
- **Embedding rule unchanged:** the writer still decides from each file's own `fsType` bits (deckFontRules.ts). A
  published file whose bits forbid embedding: stop and report (none should).
- **Size.** Report the bytes added to the repository and to the built app (`npm run build`, the dist folder's .ttf
  total before and after). The files load lazily; nothing is added to the first load. If the total added is over
  25 MB, stop and report before going on.

  of that family (name table), with that OS/2 weight, no `fvar` table, even-length glyphs, and `fsType` bits that

  can't change unnoticed).
